# Predictive Analytics: Stock Prediction, Sales Forecasting \& Waiter Tips Regression

Real-life predictive analytics project comparing three model types on three different
problems: an LSTM neural network for stock price prediction, Holt-Winters Exponential
Smoothing for sales forecasting, and a regression model (baseline through three
refinements) for restaurant tip prediction, packaged into a deployable pipeline.

This project uses a **self-generated synthetic dataset** (`synthetic_predictive_analytics_dataset_v2.xlsx`),
built with the same structure as the course-provided dataset (3 tickers, 4 stores, 300
restaurant bills) but with entirely new company names, stores, and values, generated in
`data/generate_dataset.py`.

## Project summary

* **Stock prediction (NOVATECH ticker):** an LSTM trained on 20-day sliding windows of
closing price, evaluated on a time-based (not random) train/test split.
* **Sales forecasting (Harborview store):** seasonal decomposition followed by Holt-Winters
Exponential Smoothing, evaluated on the most recent 60 days.
* **Waiter tips regression:** a plain baseline (bill amount only), compared against three
refinements — full feature set with linear regression, Ridge regression, and Random
Forest — evaluated on a held-out test set.
* **Deployment:** the best-performing tips model is saved as a single pipeline file
(preprocessing + model together) and reloaded to predict on new, unseen inputs.

Full results and metrics are in [`outputs/all\_results.json`](outputs/all_results.json) and
[`outputs/tips\_model\_comparison.csv`](outputs/tips_model_comparison.csv).

## How to run

1. Clone this repository:

```bash
   git clone https://github.com/shafiqulSQL/Predictive-Analytics.git
   cd Predictive-Analytics
   ```

2. Install dependencies:

```bash
   pip install -r requirements.txt
   ```

3. (Optional) Regenerate the dataset from scratch:

```bash
   python data/generate\_dataset.py
   ```

4. Launch Jupyter and open the notebook:

```bash
   jupyter lab notebooks/predictive\_analyticst.ipynb
   ```

5. Run all cells top to bottom. Outputs (charts, metrics, the saved pipeline) are written
to the `outputs/` folder.

## Datasets

|Sheet|Contents|
|-|-|
|`Stock_Prices`|3 tickers (NOVATECH, HARBORGO, SOLARIX), 750 trading days each, OHLC + volume|
|`Sales_Data`|4 stores (Uptown, Lakeside, Harborview, Prairie), 730 days of daily sales with trend and seasonality|
|`Waiter_Tips`|300 restaurant bills with tip, party size, day, time, sex, and smoker status|

All data is synthetic, generated for this project — see `data/generate_dataset.py` for the
exact generation logic (trend, weekly/yearly seasonality, and noise parameters per
ticker/store).
